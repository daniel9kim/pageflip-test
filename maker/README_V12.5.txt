PAGE FLIP Maker V12.5 — 기존 앨범 사진 추가

변경 사항
1. 기존 앨범 수정 화면의 사진 목록 바로 위에 '+ 사진 추가' 버튼을 명확하게 표시
2. 모바일에서는 버튼을 가로 전체 폭으로 크게 표시
3. 선택한 새 사진은 기존 앨범의 마지막에 추가 대기
4. 새 사진 썸네일에서 × 버튼으로 저장 전 추가 취소 가능
5. '수정 저장' 시 새 사진만 WebP 변환/업로드하고 album.json과 책장 정보를 갱신
6. 저장 후 기존 순서 변경/삭제/표지 변경 기능은 그대로 유지
7. Worker V10.4는 변경하지 않아도 됨

권장 테스트
- 기존 앨범 수정 → + 사진 추가 → 사진 1~2장 선택
- 새 사진 썸네일/추가 대기 메시지 확인
- 수정 저장 → GitHub Pages 반영 완료 확인
- Viewer에서 추가 사진이 마지막에 들어갔는지 확인
