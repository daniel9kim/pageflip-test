PAGE FLIP Maker V12.6 — 모바일 사진 순서 변경

추가 기능
- 기존 앨범 수정 화면의 각 사진 아래에 ← / → 버튼 표시
- 모바일에서 드래그하지 않고 한 칸씩 사진 순서를 변경
- 첫 사진의 ←, 마지막 사진의 → 버튼은 자동 비활성화
- PC의 기존 드래그 순서 변경 기능은 그대로 유지
- 표지 사진을 이동해도 coverIndex가 새 위치에 맞게 자동 추적
- 새로 추가한 사진도 저장 전 ← / → 버튼으로 순서를 조정 가능
- Worker V10.4 변경 없음

검증
- app.js JavaScript 문법 검사
- 기존 moveExistingPhoto 로직 재사용
- 첫/마지막 경계 검사
- 클릭 이벤트가 표지 선택으로 전파되지 않도록 차단
- 모바일 터치용 버튼 크기 확대
