PAGE FLIP Viewer V9.4 — Real Page Turn

목표
- V9.3.2에서 확정한 레이아웃은 그대로 유지
- 페이지 넘김 동작만 실제 포토북에 가깝게 개선

변경
- 오른쪽 아래 모서리에서 시작하는 종이 말림 강화
- 넘기는 동안 종이의 곡면/뒷면 명암 강화
- 중앙 제본부를 지날 때 그림자가 자연스럽게 깊어짐
- 페이지가 왼쪽으로 내려앉는 애니메이션을 조금 더 묵직하게 조정
- 드래그 넘김에도 동일한 효과 적용
- 모바일/키보드/버튼 기존 기능 유지

변경하지 않음
- Episode 페이지
- 세로+세로 레이아웃
- 가로 Hero Spread V9.3.2
- 정사각형 사진
- 홀수 세로 + 이야기 페이지
- Maker / Worker

3. 클릭/키보드 다음 페이지에서 조금 더 묵직한 넘김
4. 기존 사진 레이아웃이 변하지 않았는지
